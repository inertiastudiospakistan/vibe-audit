Supabase service_role key shipped in codecritical
.env:1 · Secrets

What this means: A service_role key bypasses ALL row-level security. Anyone who reads this file can read and write every row in the database.

Why it matters: This is the single most dangerous finding in a Supabase app. It turns the database into a public one.

Fix it:

  1. Move the key to a server-only env var (SUPABASE_SERVICE_ROLE_KEY) that is never bundled into client code.
  2. Rotate the key in the Supabase dashboard (Settings → API → service_role → Rotate).
  3. Use the anon key in the browser, and run privileged work through a server route or Edge Function.
